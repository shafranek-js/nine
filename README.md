# Девятка / Monte Carlo (Gamos, 1993) — Web 1:1 Restoration

Полноценное 1:1 веб-восстановление классической MS-DOS карточной игры **«Девятка» (*Monte Carlo*, `NINE.EXE`, Gamos, 1993)** на современном веб-стеке (**TypeScript + Vite + PixiJS v8 + Web Audio API**).

Главная цель этапа — точное визуальное, звуковое и геймплейное соответствие оригиналу (`640×350` EGA, оригинальные спрайты, правила, 3-уровневый ИИ, музыка AdLib OPL2 и бинарно совместимый формат сохранений `NINE.RES` / `NINE.CFG`) с чистой архитектурой для дальнейшего развития.

## Технологический стек и архитектура

- **Рендеринг**: [PixiJS v8](https://pixijs.com/) в строгом виртуальном разрешении **`640×350`** (`TextureStyle.defaultOptions.scaleMode = 'nearest'`, `antialias: false`, `roundPixels: true`).
  - Режим **PAR 1:1** отображает квадратные пиксели `640×350`.
  - Режим **4:3 EGA CRT** растягивает изображение по пропорции классического ЭЛТ-монитора (`~1.37×` по вертикали) и опционально накладывает CRT-сканлайны.
- **Язык и сборка**: **TypeScript** (`strict: true`, `noUnusedLocals`, `noUnusedParameters`) + **Vite 6**.
- **Аудио**:
  - Собственный парсер [mscParser.ts](web/src/audio/mscParser.ts) разбирает все три `.MUS + .TIM` блока из `NINE.MSC`.
  - [opl2Engine.ts](web/src/audio/opl2Engine.ts) запускает 2-операторный FM-синтезатор OPL2 в `AudioWorklet` (с таймерным Web Audio fallback-режимом, если `AudioWorklet` недоступен).
  - [pcSpeaker.ts](web/src/audio/pcSpeaker.ts) воспроизводит импульсы квадратной волны PC Speaker: звон монеты (`6000 Гц`), слайд карты, сигнал паса/ошибки (`220 Гц`), победный гудок (`5000 Гц`) и последовательность выхода (`80/120/160 Гц`).
- **Графический пайплайн**:
  - Скрипт `web/tools/slice_assets.py` (Python + Pillow) сохраняет фоны и спрайт-листы в оригинальных координатах и аккуратно делает прозрачными скруглённые углы карт через flood-fill от границы, сохраняя `1px` чёрную рамку и чёрную внутреннюю заливку фигурных карт (J/Q/K).

## Игровая механика и бинарные форматы

- **Правила раздачи**:
  - Колода из **36 карт** (`6..A` в 4 мастях: пики, трефы, бубны, червы) раздаётся по 12 карт трём участникам (`1` — левый бот, `2` — правый бот, `3` — игрок).
  - Перед раздачей каждый вносит анте **`$20`** (`BANK = $60`).
  - Первым в раунде обязан ходить обладатель **бубновой девятки (`9♦`)**.
  - Далее в свой ход можно положить соседнюю по старшинству карту уже открытой масти (`low - 1` или `high + 1`) либо **девятку** новой масти.
  - При отсутствии допустимых ходов участник **пасует** и платит **`$20`** в `BANK`.
  - Победитель, сбросивший все карты первым, забирает весь `BANK`. Матч продолжается до банкротства одного из участников (`cash <= 0`).
- **Клубные столы и рекорды (`NINE.RES`)**:
  - 3 клубных стола определяют одновременно **сложность ИИ ботов (`1..3`)** и независимую таблицу топ-10 рекордов.
  - Файл `NINE.RES` имеет точный размер **600 байт** (`3 таблицы × 10 записей × 20 байт`): имя (`String[8] XOR 0xFF`), счёт (`int16 LE`), пароль (`String[8] XOR 0xFF`).
  - Прогресс игрока сохраняется в `localStorage` и поддерживает экспорт/импорт оригинального 600-байтового бинарного файла `NINE.RES` для полной совместимости с DOS-версией.
- **Музыкальные треки (`NINE.MSC`)**:
  - Track 0 (`intro`): `115 BPM`, `7200` тиков (`trumpet5`, `bells`, `$ynbass4`) — экран заставки.
  - Track 1 (`win_game`): `180 BPM`, `32640` тиков (`piano1` + ударные) — победа в матче.
  - Track 2 (`menu`): `120 BPM`, `34800` тиков (`bells`, `love30`, `piano1` и др.) — клубное меню.

## Быстрый старт

### Требования
- **Node.js** `18+` и **npm**
- *(Опционально, только для пересборки ассетов)* **Python 3** с пакетом `Pillow`

### Установка и запуск

```powershell
cd web
npm install
npm run dev
```

После запуска откройте в браузере адрес, который выведет Vite (обычно `http://localhost:5173/`).  
> **Примечание:** браузеры блокируют автозапуск звука до первого жеста пользователя — клик по экрану, нажатие клавиши или кнопка `Audio` в нижней панели сразу активируют AdLib FM-синтезатор и PC Speaker.

## Управление

### Заставка (`IntroScene`)
- Клик мышью или нажатие `Space` / `Enter` / `Esc` / любой клавиши переходит в клубное меню.

### Клубное меню (`ClubMenuScene`)
- **`F1`** / **`1`** или клик по левому персонажу — начать партию (если вход не выполнен, автоматически откроется окно ввода имени и пароля).
- **`F2`** / **`2`** или кнопка с наушниками — включить / выключить музыку и звуки (`NINE.CFG`).
- **`F3`** / **`3`** или центральный персонаж — переключить клубный стол (`Table #1 / #2 / #3` и сложность ИИ).
- **`F4`** / **`4`** или персонаж с планшетом / строка ввода — вход под существующим именем или регистрация нового игрока (`NEW PLAYER` → `PASSWORD`, до 8 символов).
- **`F5`** / **`5`** / **`Esc`** или персонаж у двери — выход обратно на заставку.

### Игровой стол (`GameTableScene`)
- **Клик мышью по карте** в нижней руке — сделать ход (недопустимая карта вызывает сигнал `220 Гц` и реакцию дилера).
- **`Space` / `Enter` / `P`** или клик при отсутствии ходов — пас со штрафом `$20` (также срабатывает автоматически после короткой паузы).
- **`Esc`** — вернуться в клубное меню.

### Панель оболочки (под игровым экраном)
- `Audio: ON/OFF` — управление звуком и разблокировка Web Audio.
- `Aspect: PAR 1:1 / 4:3 EGA CRT` — переключение пропорций кадра.
- `CRT Scanlines: OFF/ON` — наложение строчных сканлайнов.
- `Export NINE.RES` / `Import NINE.RES` — скачивание и загрузка 600-байтового бинарного файла рекордов.
- `Reset Save` — сброс локальных сохранений к исходным DOS-данным.

## Тестирование и сборка

Все команды выполняются из каталога `web/`:

```powershell
# Модульные тесты (правила, ИИ, бинарный кодек NINE.RES/CFG, парсер NINE.MSC)
npm test

# Проверка типов TypeScript (strict) и production-сборка в dist/
npm run build

# Предпросмотр собранной production-версии
npm run preview

# (Опционально) Перенарезка PNG-ассетов и перегенерация manifest.json
npm run slice
```
